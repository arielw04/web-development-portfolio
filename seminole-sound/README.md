# Seminole Sound — Student Radio Website

An HTML-only coursework prototype for a fictional campus radio station, with four linked pages: home, weekly schedule, song requests, and station applications.

## Demonstrates

- Semantic page sections and consistent navigation.
- Schedule tables with captions and header scopes.
- Labeled form inputs, fieldsets, legends, and browser validation attributes.
- Local images with alternative text and a titled map embed.

Open `index.html` to preview. This project deliberately has no stylesheet or JavaScript, matching its HTML assignment scope. Request and application forms have placeholder actions and do not send or store submissions. The fixed-width map needs attention before presenting this as a mobile-ready website.

Course starter material and supplied art are retained; original instructions are in `coursework/`.
