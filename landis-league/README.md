# Landis League — Intramural Sports Website

A four-page HTML/CSS coursework prototype for a fictional campus intramural league, covering game schedules, standings, team registration, and officiating applications.

## Demonstrates

- Shared stylesheet and reusable theme variables.
- Grid/Flexbox layouts, cards, and a responsive breakpoint.
- Table styling with horizontal scrolling containers.
- Styled form controls, focus states, and a consistent visual theme.

Open `index.html` to preview. Forms have placeholder actions and do not send or save registrations. Social links and artwork are placeholders. The markup and artwork were supplied as course starter material; the styling is the project contribution. Original instructions are in `coursework/`.

This is a static prototype, not a working sports-registration service.
