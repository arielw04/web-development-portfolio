# -web-development-portfolio

## Web Development Portfolio

Two coursework websites from CGS 3066, Web Programming & Design at Florida State University. These are educational prototypes using fictional/demo content and supplied placeholder artwork, not official university services.

| Project | Focus | Status |
| --- | --- | --- |
| [Landis League](landis-league/) | CSS theme, Grid/Flexbox, responsive layouts, tables and form styling | Static HTML/CSS prototype |
| [Seminole Sound](seminole-sound/) | Semantic HTML, navigation, schedules, accessible form markup | HTML-only prototype |

### Preview locally

Download the repository and open either project's `index.html` in a browser. Navigate between pages using the site menus. The map embeds require internet access. No build step is required.

### Scope and attribution

Seminole Sound extends a supplied HTML starter. Landis League uses supplied HTML and artwork with an added shared stylesheet; the CSS is the project contribution. Original course instructions and checklists are preserved in each project's `coursework/` directory. Their starter descriptions and unchecked boxes are historical assignment material, not a current feature checklist.

Only one copy of each completed project is included. Duplicate archives, alternate folder copies, unrelated saved web pages, and the untouched Nole Notes JavaScript starter are excluded. Source files and artwork are preserved byte-for-byte. `source-manifest.csv` records source locations and hashes.

### Current limits

Forms use placeholder actions and have no backend, delivery, or saved submissions. Social links are placeholders. Artwork is supplied placeholder art. These projects have not been deployed as public websites.
